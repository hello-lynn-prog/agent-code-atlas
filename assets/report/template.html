说明

Agent Code Atlas:交互式源码架构浏览器。点击架构节点、文件、符号可在右侧查看证据与行号;左侧树可按物理/逻辑组织浏览。

实现状态:implemented 本仓库实现 · delegated 委托给宿主/依赖 · partial 部分实现 · unknown 证据不足 · absent 设计上不提供

证据等级:runtime(实际运行) > test(测试) > code(实现源码) > config(配置/依赖) > docs(文档声称) > inference(推断,附依据)。

本报告为离线单文件,所有数据已内嵌;链接均为页面内深链接,可用浏览器前进/后退。
